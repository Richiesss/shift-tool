# SDU-Shift

飲食店向けのシフト表自動生成デスクトップアプリケーションです。  
従業員の希望シフトをパターンから選択するだけで、制約条件を満たした最適なシフト表を自動生成します。

---

## 主な機能

| 機能 | 内容 |
|---|---|
| 従業員管理 | 氏名・雇用形態・ポジション別習熟度を登録 |
| 希望シフト入力 | 2週間単位でシフトパターン（14種類）またはカスタム時刻を入力 |
| シフト自動生成 | CP-SATソルバーによる最適化（正社員優先・人件費・希望を考慮） |
| シフト編集 | 生成結果をカレンダー形式で確認・手動修正 |
| 出力 | PDF・Excel（.xlsx）形式でエクスポート（従業員×日付マトリクス形式） |

---

## シフトパターン

希望シフト入力では以下のパターンから選択できます。

| パターン | 時間 |
|---|---|
| 朝食短番 | 6:00 〜 10:00 |
| 朝食 | 6:30 〜 11:30 |
| 朝食ロング | 5:45 〜 14:45 |
| 午前半日 | 6:30 〜 15:30 |
| 中番 | 10:00 〜 15:00 |
| 通し早番 | 13:00 〜 22:30 |
| 通し遅番 | 14:00 〜 23:00 |
| ディナー | 17:00 〜 22:30 |
| ディナー遅番 | 17:30 〜 23:00 |
| ディナーロング | 16:00 〜 23:00 |
| ランチ＋ディナー | 11:00 〜 16:00 / 17:00 〜 23:00 |
| ダブル | 朝食＋ディナー（通し） |
| カスタム入力 | 任意の開始・終了時刻 |

| 時間帯 | ポジション | 最低 | 最大 |
|---|---|---|---|
| 朝食 | ホール | 1名 | 8名 |
| 朝食 | キッチン | 0名 | 4名 |
| ディナー | ホール | 2名 | 8名 |
| ディナー | キッチン | 1名 | 5名 |

---

## 最適化の優先順位

1. **正社員優先充当** — 正社員が希望した枠には必ず充当し、余りをアルバイトで補完
2. 人件費の最小化（総労働時間の削減）
3. 残業・深夜勤務の特定人物への集中を回避
4. 従業員の希望をなるべく通す（アルバイト）
5. 各日の人員配置のバランスを均等化

## Windows EXEのダウンロード

**[Releases](https://github.com/Richiesss/shift-tool/releases)** から最新の `SDU-Shift.exe` と `shift_tool.db` をダウンロードし、**同じフォルダに置いて**実行してください。

| ファイル | 説明 |
|---|---|
| `SDU-Shift.exe` | アプリ本体 |
| `shift_tool.db` | テストデータ入りDB（2024年3月1〜15日・38名） |

> 初回起動時に Windows Defender のスキャンで数秒かかる場合があります。  
> SmartScreen の警告が出た場合は「詳細情報」→「実行」で起動できます。

## データの保存先

| 実行方法 | 保存先 |
|---|---|
| EXE実行 | EXEと同じフォルダの `shift_tool.db` |
| 開発環境（python main.py） | `~/.shift_tool/shift_tool.db` |

## セットアップ（開発環境）

```bash
git clone https://github.com/Richiesss/shift-tool.git
cd shift-tool
pip install -r requirements.txt
python main.py
```

**動作確認済み環境**: Python 3.11以上 / Windows 10・11

### テストデータの投入

```bash
python scripts/seed_test_data.py --reset
```

2024年3月1〜15日の実績シフト（38名）がDBに登録されます。
