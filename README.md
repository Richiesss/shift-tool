# シフト表構築ツール

飲食店向けのシフト表自動生成デスクトップアプリケーションです。  
従業員の希望シフトを入力するだけで、制約条件を満たした最適なシフト表を自動生成します。

---

## 主な機能

| 機能 | 内容 |
|---|---|
| 従業員管理 | 氏名・雇用形態・ポジション別習熟度・固定シフトパターンを登録 |
| 希望シフト入力 | 2週間単位で従業員ごとに勤務可能日・時間帯を入力 |
| シフト自動生成 | CP-SATソルバーによる最適化（人件費・スキルバランス・希望を考慮） |
| シフト編集 | 生成結果をカレンダー形式で確認・手動修正 |
| 出力 | PDF・Excel（.xlsx）形式でエクスポート |

---

## 店舗設定

| 時間帯 | 時間 | ポジション | 最低人数 | 最大人数 | ベテラン以上 |
|---|---|---|---|---|---|
| 朝食 | 6:00〜11:00 | ホール | 3名 | 4名 | 2名以上 |
| 朝食 | 6:00〜11:00 | キッチン | 3名 | 3名 | 1名以上 |
| ディナー | 17:00〜23:00 | ホール | 3名 | 3名 | 1名以上 |
| ディナー | 17:00〜23:00 | キッチン | 3名 | 3名 | 1名以上 |

## 技術スタック

| 用途 | ライブラリ |
|---|---|
| GUI | PyQt6 |
| 最適化 | Google OR-Tools（CP-SAT） |
| データベース | SQLite |
| Excel出力 | openpyxl |
| PDF出力 | reportlab |
| ビルド | PyInstaller + GitHub Actions |

---

## 最適化の優先順位

1. 人件費の最小化（総労働時間・残業・深夜割増の削減）
2. 残業・深夜勤務の特定人物への集中を回避
3. 従業員の希望をなるべく通す
4. 各日の人員配置のバランスを均等化

## セットアップ（開発環境）

```bash
git clone https://github.com/Richiesss/shift-tool.git
cd shift-tool
pip install -r requirements.txt
python main.py
```

**動作確認済み環境**: Python 3.11以上 / Windows 10・11

---

## Windows EXEのダウンロード

mainブランチへのプッシュ時にGitHub Actionsが自動でビルドします。

**[Releases](https://github.com/Richiesss/shift-tool/releases)** から最新の `シフト表構築ツール.exe` をダウンロードして実行してください。

> 初回起動時にWindows Defenderのスキャンで数秒かかる場合があります。  
> SmartScreen の警告が出た場合は「詳細情報」→「実行」で起動できます。

---

## データの保存先

アプリのデータ（従業員情報・シフト履歴）はローカルに保存されます。

```
Windows: C:\Users\<ユーザー名>\.shift_tool\shift_tool.db
Linux:   ~/.shift_tool/shift_tool.db
```
