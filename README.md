# SDU-Shift

飲食店向けのシフト表自動生成Webアプリケーションです。  
従業員の希望シフトをパターンから選択するだけで、制約条件を満たした最適なシフト表を自動生成します。

---

## 主な機能

| 機能 | 内容 |
|---|---|
| 従業員管理 | 氏名・雇用形態・所属ポジション・勤務時間帯・ポジション別習熟度を登録 |
| 希望シフト入力 | 2週間単位でシフトパターン（14種類）またはカスタム時刻を入力 |
| シフト自動生成 | CP-SATソルバーによる最適化（正社員優先・リーダー要件・ポジション制約を考慮） |
| シフト編集 | 朝食/ディナー別タブのカレンダー形式で確認・手動修正。他時間帯専任メンバーのワンタッチ表示切替 |
| バックアップ/インポート | データをJSON形式でダウンロード・復元 |
| ダークモード | OS設定に連動した自動切替（Light / Dark） |
| 出力 | PDF・Excel（.xlsx）形式でエクスポート（従業員×日付マトリクス形式） |

---

## 従業員属性

各従業員には以下の属性を設定できます。

| 属性 | 選択肢 | 説明 |
|---|---|---|
| 雇用形態 | 正社員 / アルバイト | アルバイトは2週間単位で希望シフトを入力 |
| 所属ポジション | どちらでも / ホール専任 / キッチン専任 | 専任設定はシフト自動生成の硬制約 |
| 勤務時間帯 | どちらでも / 朝食専任 / ディナー専任 | シフト表示タブのデフォルトフィルタに使用 |
| ホール習熟度 | リーダー / ベテラン / 一般 / 新人 | ホールのリーダー要件に反映 |
| キッチン習熟度 | リーダー / ベテラン / 一般 / 新人 | キッチンのリーダー要件に反映 |

## シフトパターン

希望シフト入力では以下のパターンから選択できます。

| パターン | 時間 |
|---|---|
| 朝食短番 | 6:00 〜 10:00 |
| 朝食 | 6:30 〜 11:30 |
| 朝食ロング | 5:45 〜 14:45 |
| 午前半日 | 6:30 〜 15:30 |
| 中番 | 10:00 〜 15:00 |
| 通し早番 | 13:00 〜 22:30 |
| 通し遅番 | 14:00 〜 23:00 |
| ディナー | 17:00 〜 22:30 |
| ディナー遅番 | 17:30 〜 23:00 |
| ディナーロング | 16:00 〜 23:00 |
| ランチ＋ディナー | 11:00 〜 16:00 / 17:00 〜 23:00 |
| ダブル | 朝食＋ディナー（通し） |
| カスタム入力 | 任意の開始・終了時刻 |

## シフト制約（人員要件）

| 時間帯 | ポジション | 人数 | リーダー最低 |
|---|---|---|---|
| 朝食 | ホール | 3〜4名 | 1名 |
| 朝食 | キッチン | 3名固定 | 1名 |
| ディナー | ホール | 2〜3名 | 1名 |
| ディナー | キッチン | 3名固定 | 2名 |

---

## 最適化の優先順位

1. **ポジション制約** — 専任設定のある従業員は該当ポジション以外に配置しない
2. **リーダー要件** — 各スロット・ポジションのリーダー最低人数を保証
3. **正社員優先充当** — 正社員が希望した枠には必ず充当し、余りをアルバイトで補完
4. 人件費の最小化（総労働時間の削減）
5. 残業・深夜勤務の特定人物への集中を回避
6. 従業員の希望をなるべく通す（アルバイト）
7. 各日の人員配置のバランスを均等化

## セットアップ（開発環境）

```bash
git clone https://github.com/Richiesss/shift-tool.git
cd shift-tool
pip install -r requirements.txt
python web_app.py
```

`http://localhost:5000` でアクセスできます。`DATABASE_URL` 未設定時はSQLite（`~/.shift_tool/shift_tool.db`）にフォールバックします。設定画面のバックアップ機能を使うと、データをJSON形式で保存・復元できます。

**動作確認済み環境**: Python 3.11以上
