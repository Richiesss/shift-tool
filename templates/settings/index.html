Google クライアントID・シークレットの取得手順（クリックで展開）
  1. Google Cloud Console にアクセス
    Google Cloud Console にアクセスし、Googleアカウントでログインします。
  2. プロジェクトの作成と選択
    画面上部のプロジェクト選択ドロップダウンから「新しいプロジェクト」を作成（または既存のプロジェクトを選択）します。
  3. API の有効化
    左側メニューの「APIとサービス」＞「ライブラリ」から、以下の2つのAPIを検索して有効化します。
    ・Google Forms API
    ・Google Drive API
  4. OAuth 同意画面の設定
    左側メニューの「APIとサービス」＞「OAuth 同意画面」を開き、User Type で「外部」を選択して「作成」を押します。
    アプリ名や連絡先メールアドレスなどの必須項目を入力し、「保存して次へ」を進めます。（スコープは変更不要です）
    最後の「テストユーザー」画面で、「+ ADD USERS」を押して連携させたい店長の Gmail アドレスを必ず登録してください（※アプリ承認前は登録されたテストユーザーのみ接続可能です）。
  5. 認証情報の作成
    左側メニューの「APIとサービス」＞「認証情報」を開き、上部の「+ 認証情報を作成」から「OAuth 2.0 クライアント ID」を選択します。
    ・アプリケーションの種類: ウェブ アプリケーション
    ・名前: SDU-Shift など
    ・承認済みのリダイレクト URI: 上記のコピーしたリダイレクトURIを追加
  6. ID とシークレットの取得
    「作成」を押すと画面に「クライアント ID」と「クライアント シークレット」が表示されます。それらをコピーして上記の入力欄に貼り付け、この設定画面の右上にある「保存」ボタンを押してください。
